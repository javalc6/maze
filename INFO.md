# Class Maze
This class generates and solves rectangular mazes using DFS and BFS algorithms without stackoverflows.
The maze itself is stored as an array of *int* cells, each cell can be an empty place or a wall or a colored place, used to perform flooding and other tasks


## Constructor
The constructor *Maze* generates a rectangular square of size *n* x *m* with exit door located on external wall.
Note that both *n* and *m* shall be odd numbers, greater than 3.

## Methods
The following methods operate on the maze generated by the *Maze* constructor:

| Method | Description |
|--------|-------------|
| `getInnerCell()` | Returns the position of the inner cell |
| `findPathMaze(Cell in, Cell out)` | Returns ArrayList<Cell> as shortest path between *in* and *out* |
| `checkReachability(Cell in)` | Checks if all empty cells are reachable starting from cell *in* |
| `cloneMaze()` | Returns maze as int[][] using deep copy |
| `clearMaze()` | Clears all cells different from WALL |

# Class Cell
This class holds the position of a place in the maze stored as *x*, *y*
